# 8 POOL FUSSION

A Unity 8-ball pool game.

## Project structure

- `Assets/Scenes/Final/` — production scenes (MainMenuScene, GameplayScene, QuickFireScene, LuckyShotScene)
- `Assets/Scripts/Gameplay/` — core gameplay scripts
- `Assets/Scripts/QuickFireModeGamePlay/`, `Assets/Scripts/LuckyShotGamePlay/` — mode-specific gameplay scripts

## Requirements

- Unity 6000.3.19f1
